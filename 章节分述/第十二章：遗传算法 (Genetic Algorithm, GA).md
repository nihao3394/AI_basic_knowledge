## 1. 概念引入与思想起源

- **进化智能 (Evolutionary Intelligence)**：借鉴自然界“适者生存、优胜劣汰”的客观规律，在**时间维度**上通过代际繁衍、基因突变与自然选择来求解复杂优化问题。
    
- **基本思想**：从一个初始解集（初始种群）出发，应用**选择、交叉、变异**等遗传算子，逐代演化迭代，逐步逼近最优解。

### 选择

**效果**：提高了群体的平均适应值；损失了群体的多样性。
**特点**：选择操作没有产生新的个体；群体中最好个体的适应值不会改变。

### 交叉

假如交叉概率 $P_c$=70%，则交配池中70%的染色体(一半染色体)将进行交叉操作，余下的30%的染色体进行选择(复制)操作。

**效果**：遗传算法利用选择和交叉操作可以产生具有更高平均适应值和更好染色体的群体。

## 2. 基础名词映射

| **生物学概念**            | **遗传算法中的含义**                   |
| -------------------- | ------------------------------ |
| **种群 (Population)**  | 问题可行解的集合                       |
| **个体 (Individual)**  | 种群中的单个解                        |
| **群体 (Population)**  | 被选定的一组解                        |
| **染色体 (Chromosome)** | 对解进行编码后的数据串（如二进制串或整数数组）        |
| **基因 (Gene)**        | 编码串中的具体某一位                     |
| **适应度 (Fitness)**    | 评价个体优劣的度量函数（基于目标函数计算，适应度越高越优秀） |
| **表现型（Phenotype）**   | 问题本身所需要的实际解，也就是解在问题空间中的具体表现    |
| **基因型（Genotype）**    | 表现型经过编码后，得到的计算机可以进行遗传操作的数据表示   |
| **编码（Encoding）**     | 将表现型映射为基因型                     |
| **解码（Decoding）**     | 将基因型还原为表现型                     |
| **交叉 (Crossover)**   | 以一定的方式由双亲产生后代的过程               |
| **变异 (Mutation)**    | 编码的某些分量发生变化的过程                 |

## 3. 标准遗传算法的四大步骤与流程

### 步骤 1：编码与初始化种群 (Encoding & Initialization)

- **编码**：将实际问题的参数映射为染色体（例如：求解方程中的变量 $X_1, X_2 \dots$ 分别作为染色体上的各个基因）。
    
- **初始化**：随机生成 $N$ 条染色体，组成第 $0$ 代初始种群 $P(0)$。

### 步骤 2：选择算子 (Selection) —— 减少多样性、保留优良基因

- **轮盘赌选择法 (Roulette Wheel Selection)**：
    
    - 个体**被选中的概率**取决于其相对适应度大小：  
        $$P(x_i) = \frac{f(x_i)}{\sum_{j=1}^N f(x_j)}$$
    - 其中：
		
		- 设种群规模为 $N$，$x_i$ 为种群中第 $i$ 个染色体；
			
		- $f(x_i)$ 为第 $i$ 个染色体的适应值；
			
		- $\sum_{j=1}^N f(x_j)$ 为种群所有染色体适应值的总和；
		
	- 适应度越高的个体在圆盘中所占扇区面积越大，被抽中延续到下一代的概率越高。
        
    - **操作**：计算各累积概率，生成随机数 $\text{Uniform}(0,1)$ 决定淘汰与留存。
	    
### 步骤 3：交叉算子 (Crossover) —— 产生新解的主力

按交叉概率 $P_c$（如 $P_c = 0.25$）随机选择亲本染色体进行基因重组：

- **单点交叉 (Single-point Crossover)**：随机设定一个交叉点，交换父代染色体在该点前后的基因段。
    
- **多点交叉 / 两点交叉**：设定多个切割点进行分段基因交换。

### 步骤 4：变异算子 (Mutation) —— 增加多样性、防止局部最优

按变异概率 $P_m$（通常较小，如 $P_m = 0.12$）随机修改某些基因的值：

- 计算总基因数：$\text{总基因数} = \text{种群大小} \times \text{染色体长度}$。
    
- 需要变异的基因数：$\text{突变基因数} = \text{总基因数} \times P_m$。
    
- 随机挑选位置并重新赋予随机值，以此跳出局部最优陷阱。

### 总结

完整的数据处理过程是：

**随机产生初始种群 → 表现型 → 编码 → 基因型（染色体）→ 选择、交叉、变异 → 新基因型 → 解码 → 新表现型 → 适应度评价。**

## 4. 经典应用案例图解（方程求根）

### 问题设定

求解方程：$3X_1 + 2X_2 + 4X_3 + 2X_4 + 5X_5 = 100$ ，约束条件：$X_i$ 为 $0 \sim 9$ 的非负整数。

### 计算步骤演练：

1. **构造目标函数与误差**：  
    $$f(x) = \vert{}3X_1 + 2X_2 + 4X_3 + 2X_4 + 5X_5 - 100\vert{}$$
2. **构建适应度函数 (Fitness Function)**：  
    $$F(c) = \frac{1}{1 + f(x)}$$
    - 遗传算法的机制是“优胜劣汰”（适应度越高越容易被选中）。由于我们需要寻找使误差最小的解，因此通过取倒数的方式，让误差 $f(x)$ 越小的个体，其对应的适应度 $F(c)$ 越高。
    - **防止分母为零**：在分母中人为加上 $1$，即 $1 + f(x)$。这样当误差 $f(x) = 0$（即完美命中目标值 $100$）时，分母仍有意义（分母为 $1$），避免了数学上的除以零错误。
    
3. **选择**：按适应度比例计算轮盘赌概率，生成随机数挑选生存者。
    
4. **交叉**：选定交叉点（例如在第2个基因后切开），互相交换后半段。
    
5. **变异**：随机选中变异点，将原有数字替换为新生成的随机数 ($0 \sim 9$)。
    
6. **终止评估**：重复上述代际迭代，直至找到 $f(x) = 0$ 的染色体组合（即最优解）。
